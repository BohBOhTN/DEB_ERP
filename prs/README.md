# Pull Request Briefs

This folder stores prepared pull request briefs for feature branches merging into `dev`.

Use one file per pull request. Keep each brief factual, concise, and tied to the sprint scope. Do not include marketing language, unsupported claims, or broad future promises.

Recommended file name:

```text
NNN-release-sprint-short-name.md
```

Example:

```text
001-r0-sprint-0-foundation.md
```
